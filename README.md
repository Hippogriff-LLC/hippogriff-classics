# Hippogriff Classics

Open-source common platform for Hippogriff Classics.

This repository owns shared library/site/import/runtime/platform concerns that are genuinely
common across supported titles. Title-specific reverse-engineering and reconstruction remain
in separate `hippogriff-classics-<title>` repositories.

## Public/private boundary

Hippogriff may publish independently authored analyzers/recompilers, runtimes, compatibility
layers, platform/browser/app integration, tests, build tooling, and safe reverse-engineering
knowledge. Original proprietary executables/assets and mechanically reconstructed copyrighted
implementation remain outside public Git under governed CSJS Drive storage.
